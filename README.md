# Щоденний дайджест світових новин у Telegram

Щоранку о 7:00 (Київ) бере найважливіші свіжі новини з BBC World, Al Jazeera та NPR World і надсилає короткий дайджест у ваш Telegram-чат/канал. Працює безкоштовно на GitHub Actions — не потрібен жоден власний сервер.

## Крок 1. Створити Telegram-бота

1. Відкрийте в Telegram чат з **@BotFather**
2. Надішліть `/newbot`, дайте боту ім'я та юзернейм
3. BotFather видасть **токен** виду `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — збережіть його

## Крок 2. Визначити, куди слати повідомлення

**Варіант А — особисті повідомлення собі:**
1. Знайдіть у Telegram бота **@userinfobot**, натисніть Start — він покаже ваш `chat_id`
2. Напишіть повідомлення своєму новому боту (просто "привіт") — це потрібно, щоб бот міг вам писати першим

**Варіант Б — канал:**
1. Створіть Telegram-канал (публічний або приватний)
2. Додайте вашого бота як адміністратора каналу
3. `chat_id` каналу — це `@your_channel_username` (для публічного) або числовий ID (для приватного, можна дізнатись через @userinfobot після пересилання повідомлення з каналу)

## Крок 3. Завантажити цей код на GitHub

1. Створіть новий репозиторій на github.com (можна приватний)
2. Завантажте туди всі файли з цієї папки (`news_digest.py`, `requirements.txt`, `.github/workflows/daily-news.yml`)

## Крок 4. Додати секрети в GitHub

У репозиторії: **Settings → Secrets and variables → Actions → New repository secret**

Додайте два секрети:
- `TELEGRAM_BOT_TOKEN` — токен з кроку 1
- `TELEGRAM_CHAT_ID` — chat_id з кроку 2

## Крок 5. Перевірити

У вкладці **Actions** репозиторію знайдіть workflow "Daily Telegram News Digest" → **Run workflow** — запустіть вручну, щоб перевірити, що дайджест прийшов у Telegram.

Після цього він працюватиме автоматично щоранку — нічого запускати вручну більше не потрібно.

## Налаштування під себе

- **Час публікації**: змініть рядок `cron: "0 4 * * *"` у файлі `.github/workflows/daily-news.yml` (час у форматі UTC)
- **Джерела новин**: список `FEEDS` у `news_digest.py` — можна додати чи прибрати RSS-стрічки
- **Кількість новин**: змінна `MAX_ITEMS` у `news_digest.py`
